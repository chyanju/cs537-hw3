## What to submit

- **A write-up** of your answers to Problems 1–4, in any readable format: Markdown, plain text, LaTeX, PDF, or images (PNG or JPG), so clear scans or photos of handwritten work are fine. Label each answer with its problem number and part.

In the write-up, include the numbers your code produces (tables are fine) and explain how you got them. Also say how to run your code (for example, `python3 trapezoid.py`), since the TA may run it.

## How to submit

Put all your files in this repository; the top level is fine. Leave the provided files (`Math104A-HW01.pdf` and `src/`) unchanged. The PDF mentions Canvas, but for this course you submit here instead.
